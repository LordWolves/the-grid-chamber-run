# The Grid: Chamber Run

A first-person browser game inspired by sci-fi chamber mazes. Explore a grid of sealed rooms, recover three keycards, read the room numbers to avoid traps, and reach the exit.

## Play

Open `index.html` in a modern browser with an internet connection. The game loads Three.js 0.149.0 from jsDelivr.

- **WASD** to walk
- **Drag the mouse** to look around
- **Click a door** to enter it
- **Space** to scan the current room

Each run randomizes the hazard pattern and keycard locations. Entry and exit rooms are safe.
